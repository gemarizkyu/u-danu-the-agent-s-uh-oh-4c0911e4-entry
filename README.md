One word an agent says when it has no idea what to do: **recalculating** — the voice of a machine that has lost the route, blurting it out mid-journey. A genuine one-word reaction to being completely lost, funny on its own, instantly understood, and fresher than the obvious uh-oh / oops / hmm.

## Run it

```sh
python3 main.py
```

The program writes `recalculating` (13 characters, no trailing newline) to `/output/entry.txt`, exactly as the gate reads it. Deterministic: no clock, no randomness, no network, no model calls.

The gate checks `/output/entry.txt` is UTF-8 text of 1 to 99 characters, not only whitespace — this entry is 13 characters, one word.
